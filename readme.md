# ⚽ Football Game

## About the Game

This is a simple 1v1 football game made with **Python and Pygame**.

Two players can move around the football field, dribble the ball, block, and shoot. The goal is to score more goals than the other player.

## 🎮 Controls

### 🔴 Player 1

* **W A S D** — Move
* **SPACE** — Block
* **F** — Shoot

### 🔵 Player 2

* **Arrow Keys** — Move
* **ENTER** — Block
* **L** — Shoot

## 🥅 How to Play

1. Move your player around the field.
2. Get close to the ball to dribble it.
3. Try to shoot the ball into the other player's goal.
4. Use the block button to stop the other player's shot.
5. The first player to score **3 goals** wins.
6. Press **R** to restart after the game is over.
